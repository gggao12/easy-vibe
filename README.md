# Easy-Vibe 电商主图文案生成工具

基于 AI 的电商营销素材一站式生成平台，支持商品主图叠加条生成、图转文识别、AI 生图等核心功能。

## 功能模块

### 1. 首页工作台

- 实时统计：累计生成数、完成率、今日生成数
- 进度概览：各商品线生成进度可视化

### 2. 商品任务（📋 商品任务）

商品信息录入与主图叠加条生成：

- **基础信息**：商品名称、品牌、类目、属性规格（材质、颜色、尺寸、适用人群）
- **视觉素材**：卖点关键词输入
- **促销信息**：促销活动文案
- **商品图片**：上传商品主图
- **AI 文案风格**：种草推荐、促销秒杀、剧情演绎、知识科普、个人分享、买家证言
- **一键填充测试数据**：快速生成模拟数据
- **模板样式**：样式 A（天蓝底红字）、样式 B（黑底金字）
- **生成与保存**：生成叠加条效果预览，支持保存草稿

### 3. 模板库（🎨 模板库）

预设 6 种主图叠加条模板：

| 模板         | 风格               | 适用场景     |
| ------------ | ------------------ | ------------ |
| 夏日清爽风   | 天蓝背景白色边框   | 夏季服饰     |
| 高端奢华感   | 黑色渐变配金色文字 | 美妆奢侈品   |
| 简约白底     | 纯白底红色粗体     | 突出商品主体 |
| 促销 urgency | 深灰底橙红文字     | 紧迫促销氛围 |
| 清新自然     | 浅绿渐变墨绿文字   | 家居日用品   |
| 节日庆典     | 红金配色           | 节日营销活动 |

### 4. 图转文（🖼 图转文）

基于 SiliconFlow Vision API（Qwen/Qwen3-VL-8B-Instruct）的图片智能识别功能：

- 上传商品图片（支持 JPG/PNG，最大 5MB）
- AI 自动识别生成：
  - 商品名称
  - 商品类目
  - 材质
  - 颜色
  - 卖点关键词
  - 适用人群
  - 商品描述
  - 搜索关键词
- 每个识别结果支持一键复制

### 5. AI 生图（🎯 AI 生图）

基于 SiliconFlow Image API（Qwen/Qwen-Image-Edit-2509）的 AI 图像生成功能：

**生成模式**：

| 模式     | 说明             |
| -------- | ---------------- |
| 海报生成 | 主流电商促销海报 |
| 抖音首图 | 抖音电商首图风格 |
| 背景替换 | 更换商品背景     |
| 场景合成 | 主图场景化图片   |
| 节日海报 | 主流节日主题海报 |
| 自定义   | 自由描述文生图   |

**风格标签**：春节、中秋、国庆、圣诞、新年、情人节

**支持上传参考图片**（最多 3 张，base64 格式）

**详细错误提示**：API 密钥认证失败、请求频率超限、模型不可用、图片参数不匹配、内容审核未通过、请求超时、网络连接失败等

**生成结果**：可预览、下载图片、复制链接

### 6. 已生成草稿（📁 已生成草稿）

- 本地 LocalStorage 持久化存储
- 卡片式展示：缩略图、商品名、品牌、类目、保存时间
- 支持加载草稿（回填所有信息）、删除草稿
- 一键清空全部草稿

### 7. 系统设置（⚙ 设置）

- 默认主图样式选择
- 标题后缀模式配置
- 自动保存草稿开关
- 文字叠加位置（顶部/底部）
- 字体大小选择
- 叠加条透明度配置

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（单文件）
- **AI API**：
  - SiliconFlow Vision API（图转文）
  - SiliconFlow Image API（AI 生图）
- **存储**：LocalStorage（草稿持久化）
- **无外部依赖**：纯前端实现，可直接浏览器打开

## 快速开始

1. 直接在浏览器中打开 `index.html`
2. 或使用本地服务器：`python -m http.server 3000`（然后访问 http://localhost:3000）
   3.npm start

## API 配置

如需更换 SiliconFlow API Key，请在 `index.html` 中搜索 `SILICONFLOW_API_KEY` 进行修改：

```javascript
const SILICONFLOW_API_KEY = 'your-api-key-here';
```

## 注意事项

- 图片上传大小限制：主图 5MB，图转文 5MB，AI 生图参考图 10MB
- AI 生图默认超时时间：120 秒
- 草稿数据存储在浏览器 LocalStorage 中，清除浏览器缓存会丢失
- 部分功能需要网络连接才能调用 AI API
